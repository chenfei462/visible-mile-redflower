# 缺失卡牌美术提示词

本文档整理当前仍缺卡面图的卡牌提示词。建议逐张生成，生成后按对应 `art_key` 保存为 `assets/cards/<art_key>.png`。

## 统一生成规范

每张图都建议追加以下统一约束：

```text
生成一张完整竖版桌游卡牌成品图，不是单独插画、不是图标。卡牌完整出现在画面中，比例约 2:3，正面视角，清晰边框、标题栏、插画区、说明区和底部数值栏都保留。温暖手绘水彩 + 轻桌游 UI 风格，米色纸张纹理，柔和社区生活氛围，干净可读。不要英文、乱码、水印、照片质感、3D 渲染、过度写实、黑暗恐怖风。
```
