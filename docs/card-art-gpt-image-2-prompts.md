# GPT Image 2 Card Art Prompts

## 通用生成规范

给 GPT Image 2 生成每张图时，建议在每条提示词后都保留这段统一约束：

```text
生成一张完整竖版桌游卡牌成品图，不是单独插画、不是图标。卡牌必须完整出现在画面中，四角、边框、标题栏、插画区、说明区和底部数值栏都不能被裁掉。温暖手绘水彩 + 轻桌游 UI 风格，米色纸张纹理，柔和社区生活氛围，干净可读。卡牌比例约 2:3，正面视角，轻微纸张质感，边框清晰。不要出现英文、乱码、水印、照片质感、3D 渲染、过度写实、赛博朋克、黑暗恐怖风。
```
